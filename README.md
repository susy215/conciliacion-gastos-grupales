# Conciliación de Gastos Grupales

## Información del proyecto

* **Integrante:** Yandira Vivancos Flores
* **Tipo de proyecto:** Proyecto propio
* **Modalidad de implementación:** Por definir
* **Materia:** Interacción Hombre-Computador

## Problema inicial

Las personas que realizan actividades grupales tienen dificultades para organizar y conciliar los gastos compartidos. Necesitan llevar un registro claro del monto total, quién pagó, cuánto corresponde aportar a cada integrante, quién tiene pagos pendientes y a quién debe pagarle.

## Idea inicial

Una aplicación móvil que permita crear grupos o actividades, registrar integrantes y gastos, dividir los montos en partes iguales o diferentes, consultar los saldos pendientes y conciliar los pagos.
